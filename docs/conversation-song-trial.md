# 대화 → 가족 목소리 노래 시험 기록 (2026-11-03)

> 설계 §7.5 "차 안의 대화가 가족 목소리로 부르는 노래가 된다"의 타당성 시험.
> 실험 코드는 저장소 밖 `~/ai/convo-lab/` (convo_test.py, convo_song.py, similarity.py).
> T16(voice-lab 서비스)에서 저장소 안으로 옮긴다.

## 1. 환경
- 데스크탑 RTX 5070 Ti 16GB, Windows 11. 모든 처리를 자체 GPU에서 했다 (외부 AI 서비스 없음).
- 파이썬 환경 3개 (uv): convo-lab (PyTorch 2.7.1+cu128, transformers, speechbrain, demucs), ACE-Step 1.5, Seed-VC (Python 3.10).
- Windows 주의: 애플리케이션 제어 정책이 scipy 1.18.1의 DLL을 막았다 → convo-lab은 scipy 1.17.0으로 고정. speechbrain은 심볼릭 링크 대신 `LocalStrategy.COPY`.

## 2. 시험 데이터 (사용자 녹음 대신 공개 음성)
- Zeroth-Korean 시험 세트 (CC BY 4.0, Hugging Face `kresnik/zeroth_korean`, 화자 10명·457문장, 화자 번호·정답 문장 포함).
- 화자 118·104·121이 번갈아 4문장씩 말하는 가상 대화 114초 (문장 사이 0.6초). 화자마다 대화에 쓰지 않은 다른 문장 1개 = '가족 등록 클립'.
- 시험용 호칭: 118=엄마, 104=아빠, 121=첫째. 세 화자 모두 남성 목소리로 추정 (말소리 중앙값 105~121Hz).
- 한계: 낭독(뉴스) 문장이라 실제 가족 대화(겹쳐 말하기, 감탄, 차 소음, 아이 목소리)와 다르다.

## 3. 받아 적기·화자 구분 (설계 §7.5 2·3단계)
- 발화 분할: 프레임 에너지가 최대 -35dB보다 크면 말소리, 0.35초보다 짧은 틈은 잇고 0.5초보다 짧은 구간은 버림 → 12문장이 17구간으로 나뉨 (긴 문장 안의 쉼에서 쪼개짐).
- 받아 적기: Whisper large-v3-turbo (transformers, fp16, 한국어 지정).
- 화자 식별: speechbrain ECAPA (`spkrec-ecapa-voxceleb`) 임베딩 코사인 → 등록 클립 중 가장 높은 사람.

| 지표 | 결과 |
|---|---|
| 화자 정확도 (정답 발화마다 가장 많이 겹치는 구간) | 12/12 |
| 쪼개진 조각까지 보면 | 조각 1개만 다른 사람으로 붙음 |
| 글자 오류율 (조각 이어 붙임) | 평균 12.2%, 숫자 표기가 없는 문장만 5.7% (숫자 "이천 십 팔 년"이 "2018년"으로 적혀 오류로 셈) |

## 4. 대화 → 가사, 한마디 삽입 (설계 §7.5 4·5단계)
- 가사: Ollama `gemma3:12b` (8.2GB). 대화 기록 "호칭: 말" + 규칙 프롬프트 → 8.1초. 대화 속 표현("한 잔의 커피", "노란 동백꽃", "16년의 교육")이 가사에 들어갔다. 섹션 태그가 `[Verse 1]`로 나오고 줄이 길어 §7.2 검사·재요청이 필요하다.
- 첫 요청은 모델 적재(ACE-Step과 GPU 공유) 중 500 오류 → 다시 요청해 성공. 서비스화할 때 적재 대기·재시도 필요.
- 한마디: 화자마다 가장 짧은(1초 이상) 발화를 4.5초까지 잘라 INTRO·CALL·OUTRO 클립으로 → 서버(acestep_local)로 노래 생성 15.2초.

## 5. 가족 목소리로 부르기 (설계 §7.5 7·8단계)
- 원곡: ACE-Step 어쿠스틱 샘플 75초 (남성 보컬). Demucs `htdemucs` 두 갈래 분리.
- 참고 목소리: 대화에서 화자 104로 식별된 구간을 이어 28.8초.
- 변환: Seed-VC (GPL-3.0, 2025-11 보관 처리, 커밋 51383ef) `inference.py --f0-condition True --diffusion-steps 30 --fp16 True`. 75초 보컬 약 44~48초 (실시간 대비 0.64).
- 유사도: ECAPA 임베딩 코사인. 목소리가 없는 구간(반주만 남은 부분)은 빼고 잼.

| 설정 (30초 구간) | 화자 104 | 화자 118 | 화자 121 |
|---|---|---|---|
| 원곡 AI 가수 | 0.23 | 0.25 | 0.18 |
| 기본 (shift 0, cfg 0.7) | 0.51 | 0.30 | 0.15 |
| 확산 50 스텝 | 0.51 | 0.33 | 0.15 |
| cfg 1.0 | 0.53 | 0.31 | 0.16 |
| 자동 음높이 맞춤 (`--auto-f0-adjust`) | **0.69** | 0.40 | 0.15 |
| 5반음 내림 | 0.60 | 0.33 | 0.17 |
| **한 옥타브 내림 (`--semi-tone-shift -12`)** | **0.68** | 0.37 | 0.20 |
| (참고) 같은 화자 말소리끼리 | 0.82 | — | — |

- 원인: RMVPE 기준 원곡 가수 중앙값 221Hz, 화자 104 말소리 126Hz (약 9.7반음 차이). 음역이 가까울수록 닮는다.
- 자동 음높이 맞춤은 비정수 반음만큼 옮겨 반주와 키가 어긋난다 → **옥타브 단위 이동**(k = round(log2(화자 ÷ 가수)) × 12)으로 키를 유지하면서 거의 같은 유사도를 얻는다. 전체 곡: 0.53 → **0.685**.
- ACE-Step에 "deep low baritone male vocal"로 낮은 음역을 요청해도 가수 중앙값이 158Hz(이전 160Hz, 다른 측정법)로 거의 그대로 → 프롬프트로는 음역 조절이 안 된다.
- 사용자 청취: "쓸 만하다" (0.53 버전), 0.69 버전 비교 청취 요청함.

## 6. 남은 확인
- 실제 가족 대화(차 소음, 겹쳐 말하기, 감탄, 아이·여성 목소리)로 같은 지표 다시 측정.
- 아이 목소리로 변환할 때의 품질 (남성 원곡 → 아이: 옥타브 올림).
- 여러 명이 구절을 나눠 부를 때 경계의 자연스러움.
- 미세 조정(구성원별 학습)으로 0.69를 넘을 수 있는지.
- GPU 메모리: ACE-Step + Gemma 적재 시 약 11.6GB → voice-lab 모델과 함께 쓰려면 단계별 적재·해제 필요.
