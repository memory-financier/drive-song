# 가족 대화 녹음 가이드 (데모 A안)

> 설계 T19. 데모(서울→강릉)와 시연 영상에 **우리 가족의 진짜 대화**를 넣기 위한 녹음 안내와 대본.
> 녹음 파일 6개 이하(대화 1개 + 사람마다 음성 ID 1개)를 보내 주면, 앱 데모 자료로 바꿔 에뮬레이터에서 가족 목소리 노래까지 돌린다.

## 0. 먼저: 동의와 공개 범위
- 녹음 전에 가족 모두에게 알리고 동의를 받는다. **아이는 보호자가 대신 동의한다.**
  - 쓰는 곳: 공모전 시연 영상, 2차 발표(PT) 데모, 앱 데모 화면에서 나오는 노래.
- **기본은 비공개**: 가족 목소리 파일은 이 PC의 git 밖 폴더(`android/demo-private/`)에만 둔다.
  GitHub 저장소와 제출 APK에는 지금의 공개 음성 데모가 그대로 남는다. 공개까지 원하면 따로 정한다.
- 대화에 **이름·학교·주소·전화번호**는 넣지 않는다 (호칭만: 엄마, 아빠, 첫째, 둘째).

## 1. 녹음 환경 (가장 중요)
| 할 것 | 이유 |
|---|---|
| **시동을 끈 차 안**(가장 실감) 또는 조용한 방. 창문 닫고 음악·에어컨·히터·TV 끄기 | 잡음이 섞이면 누구 목소리인지 헷갈린다 |
| 휴대폰 1대를 **가운데**(컵홀더·센터 콘솔)에 화면이 위로 오게 두고, 녹음 중에는 만지지 않기 | 모두 비슷한 크기로 녹음된다 |
| 기본 녹음 앱: 갤럭시 '음성 녹음'(일반 모드) / 아이폰 '음성 메모' | 파일(m4a) 그대로 보내면 된다 |
| **두 사람이 동시에 말하지 않기.** 앞사람 말이 끝나고 **반 박자(0.5초) 쉬고** 말하기 | 겹치면 한 사람 말로 합쳐진다 |
| 대본을 2~3번 소리 내어 읽어 본 뒤, **실제 대화처럼 편하게.** 말투를 바꾸거나 한두 마디 더해도 좋다 | 대화 속 말이 가사에 들어간다 |
| 틀리면 2초 쉬고 그 줄만 다시 말하기 (처음부터 다시 안 해도 됨) | 나중에 잘라 낼 수 있다 |
| 전체 **2분~3분** (5분을 넘기지 않기) | 앱이 5분 단위로 다룬다 |

- 사람마다 **합쳐서 10초 이상**(넉넉히 15초 이상) 말해야 그 사람 목소리로 노래를 부를 수 있다. 아래 대본은 어른 약 20초, 아이 약 15초. 아이는 천천히, 덧붙이는 말도 좋다.
- "출발~!", "아빠 최고!", "바다다!" 같은 **짧고 큰 외침**은 노래 앞·가운데·끝에 실제 목소리로 들어간다. 신나게!

## 3. 음성 ID (사람마다 따로, 5~8초)
대화와 **같은 휴대폰·같은 자리**에서, 한 사람씩 따로 녹음한다 (다른 사람은 조용히). 앱이 '누구 목소리인지' 알아보는 기준이다.
- 대사 (호칭만 바꿔서): **"안녕하세요. 저는 우리 집 ○○예요. 오늘의 드라이브 송, 지금 시작합니다."**
- 평소 말투로. 크게 외치지 않기.

## 4. 보내는 법
- 지난번처럼 채팅에 파일을 첨부한다 (m4a 그대로).
- 파일 이름에 호칭을 넣는다: `대화.m4a`, `ID_엄마.m4a`, `ID_아빠.m4a`, `ID_첫째.m4a`, `ID_둘째.m4a`.
- 아이가 몇 명인지(만 14세 미만) 함께 알려 준다.

## 5. 받은 뒤 (작업 메모)
```bash
# 저장소 루트. 결과는 git 밖 android/demo-private/assets/demo-family/ (대화·음성 ID·family.json)
python tools/demo-conversation/make_family_assets.py --conversation 대화.m4a \
  --member 엄마=ID_엄마.m4a --member 아빠=ID_아빠.m4a --member 첫째=ID_첫째.m4a:child --member 둘째=ID_둘째.m4a:child \
  --check http://127.0.0.1:8002      # voice-lab: 발화마다 누구인지, 사람마다 노래를 부를 수 있는지(참고 목소리 10초 이상)
cd android && ./gradlew :app:assembleDebug   # demo-private 가 있으면 APK 에 들어간다 (assets/demo-family/)
```
- 앱: 설정 > 데모 모드 > **데모 가족 불러오기** 가 `demo-family/family.json` 의 가족을 등록하고, 데모 주행이 `demo-family/conversation.m4a` 를 쓴다
  (없으면 공개 음성 `assets/demo/`).
- 공개 빌드(GitHub·제출 APK)는 `android/demo-private/` 를 옮겨 두고 만든다.
- 확인 후 시연 절차는 `docs/demo-scenario.md` §7 과 같다.
